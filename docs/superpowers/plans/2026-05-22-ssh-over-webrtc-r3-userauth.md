## Spec Text Adjustments

Two REMOTE-8.x entries need spec-text revisions before they can be promoted:

### REMOTE-8.5 — narrow cipher allowlist

`apple/swift-nio-ssh` 0.13.0 ships only AES-GCM transport protection schemes (`AES256GCMOpenSSHTransportProtection`, `AES128GCMOpenSSHTransportProtection`) — no ChaCha20-Poly1305. Since every iOS device since iPhone 5s and every modern Mac has hardware AES acceleration, dropping ChaCha is acceptable.

- **Before:** "the host shall restrict its SSH cipher allowlist to `chacha20-poly1305@openssh.com` and `aes256-gcm@openssh.com`"
- **After:** "the host shall restrict its SSH cipher allowlist to `aes256-gcm@openssh.com`"

### REMOTE-8.1 — stays in disabled inventory (deferred)

swift-nio-ssh 0.13.0 has no KEX-algorithm allowlist config. The library negotiates among its bundled modern ECDH algorithms (`curve25519-sha256`, `curve25519-sha256@libssh.org`, `ecdh-sha2-nistp256/384/521`); no weak/legacy KEX is offered. So strict pinning to `curve25519-sha256` only requires upstream changes to swift-nio-ssh. R3 leaves REMOTE-8.1 disabled with an "awaits upstream feature" annotation in the test's `.disabled` reason. A future PR re-promotes it once upstream support lands (or once we patch our fork).

Both adjustments land in Task 1 alongside `SPECS.md` regeneration; the design doc `2026-05-21-ssh-over-webrtc-design.md` §7.2 + §12.1 are updated to match.

## Important Context for the Implementer

### Existing trust types

These already exist on `main`. Read them before writing the delegates:

- **`TrustedPeerStore`** (`Sources/GrafttyKit/Remote/TrustedPeerStore.swift`) — file-backed JSON store of `TrustedPeer` records. Has `add/remove/update/get(id:)/contains(fingerprint:)/list()`. **Lacks `get(fingerprint:)` returning a `TrustedPeer?`** — Task 2 adds it.
- **`TrustedPeer`** (`Sources/GrafttyKit/Remote/TrustedPeer.swift`) — has `id: RemoteDeviceID`, `kind: RemoteDeviceKind`, `publicKey: RemoteIdentityPublicKey`, `displayName`, `capabilities: PairedDeviceCapabilities`, `pairedAt`, `lastSeenAt`, computed `fingerprint`.
- **`PinnedHost`** (`Sources/GrafttyMobileKit/Remote/PinnedHostStore.swift`) — host-side identity record on the client. Has `id`, `kind`, `publicKey`, `displayName`, `pairedAt`, `pairingURL`, computed `fingerprint`.
- **`PinnedHostStore`** (same file) — file-backed JSON store. Has `get(fingerprint:)` already.
- **`HostIdentityStore`** (`Sources/GrafttyKit/Remote/HostIdentityStore.swift`) — server's Ed25519 keypair persistence.
- **`ClientIdentityStore`** (`Sources/GrafttyMobileKit/Remote/ClientIdentityStore.swift`) — client's Ed25519 keypair persistence. (`#if canImport(UIKit)`-guarded.)
- **`RemoteIdentityPublicKey`** + **`RemoteIdentityFingerprint`** (`Sources/GrafttyProtocol/RemoteDeviceIdentity.swift`) — the 32-byte Ed25519 pubkey wrapper and its SHA-256-based fingerprint type.

### Mapping `NIOSSHPublicKey` ↔ `RemoteIdentityFingerprint`

The server's userauth delegate gets an `NIOSSHPublicKey` from swift-nio-ssh. To look it up in `TrustedPeerStore`, derive a `RemoteIdentityFingerprint`:

```swift
import NIOSSH
import GrafttyProtocol

func fingerprint(of nioKey: NIOSSHPublicKey) throws -> RemoteIdentityFingerprint {
    // swift-nio-ssh's NIOSSHPublicKey exposes the underlying key via
    // backingKey. For Ed25519 keys, that's a Curve25519.Signing.PublicKey
    // whose rawRepresentation is the 32-byte ed25519 pubkey.
    var buffer = ByteBufferAllocator().buffer(capacity: 64)
    nioKey.write(to: &buffer)
    // The wire format buffer holds key-type prefix + the 32-byte raw
    // pubkey. Read swift-nio-ssh's NIOSSHPublicKey docs to extract the
    // raw bytes correctly. Alternative: pattern-match on the public
    // representation API the library exposes.
    // ...
}
```

**Hint for the implementer:** swift-nio-ssh's `NIOSSHPublicKey` has an internal representation enum. Look at how `NIOSSHPrivateKey(ed25519Key:)` and `.publicKey` round-trip in swift-nio-ssh's own tests in `.build/checkouts/swift-nio-ssh/Tests/`. There's typically a method to extract the raw key bytes for Ed25519 keys without going through wire format.

If the cleanest path is to write the key to a `ByteBuffer` and decode the wire format manually, that works — SSH wire format is just `<u32 type-string length><type string><u32 key length><key bytes>` per RFC 4253 §6.6.

### Username-ignored property (REMOTE-8.3)

swift-nio-ssh's `NIOSSHUserAuthenticationRequest` exposes `username: String` and `serviceName: String`. The server delegate sees both. To implement key-only identity:

```swift
func requestReceived(
    request: NIOSSHUserAuthenticationRequest,
    responsePromise: EventLoopPromise<NIOSSHUserAuthenticationOutcome>
) {
    // Deliberately ignore request.username. Identity = pubkey only.
    switch request.request {
    case .publicKey(let publicKeyRequest):
        do {
            let fp = try fingerprint(of: publicKeyRequest.publicKey)
            if let peer = try store.get(fingerprint: fp) {
                responsePromise.succeed(.success)
            } else {
                responsePromise.succeed(.failure)
            }
        } catch {
            responsePromise.fail(error)
        }
    default:
        responsePromise.succeed(.failure)  // REMOTE-8.2: publickey-only
    }
}
```

- [ ] **Step 1: Read swift-nio-ssh's NIOSSHPublicKey API**

Before writing, read enough of swift-nio-ssh to know how to extract raw Ed25519 bytes from an `NIOSSHPublicKey`. Useful spots:

```bash
grep -rn "NIOSSHPublicKey" .build/checkouts/swift-nio-ssh/Sources/NIOSSH/*.swift | head -20
cat .build/checkouts/swift-nio-ssh/Sources/NIOSSH/NIOSSHPublicKey.swift | head -80
```

There's typically a `write(to:)` method that serializes to SSH wire format, plus an internal representation. For Ed25519 keys, the wire format is:

```
string  "ssh-ed25519"
string  ed25519_public_key_bytes  // 32 bytes
```

Per SSH wire format (RFC 4253 §5):
- string = `<u32 length, big-endian><bytes>`

So the bytes 32 onward (after the length-prefixed type string and the length-prefixed key bytes prefix) are the 32-byte Ed25519 pubkey.

- [ ] **Step 2: Create the delegate file**

Create `Sources/GrafttyHostAgent/SSH/SSHUserAuthDelegate.swift`:

```swift
import Foundation
import GrafttyKit
import GrafttyProtocol
import NIO
import NIOSSH

/// @spec REMOTE-8.2
/// @spec REMOTE-8.3
/// Server-side userauth delegate that backs SSH authentication against
/// graftty's `TrustedPeerStore`. Identity is key-only — the SSH
/// userauth `username` field is deliberately ignored; the peer is
/// resolved entirely by the offered Ed25519 public key.
public struct SSHUserAuthDelegate: NIOSSHServerUserAuthenticationDelegate {
    public let supportedAuthenticationMethods: NIOSSHAvailableUserAuthenticationMethods = .publicKey

    private let store: TrustedPeerStore

    public init(store: TrustedPeerStore) {
        self.store = store
    }

    public func requestReceived(
        request: NIOSSHUserAuthenticationRequest,
        responsePromise: EventLoopPromise<NIOSSHUserAuthenticationOutcome>
    ) {
        switch request.request {
        case .publicKey(let publicKeyRequest):
            do {
                let fingerprint = try Self.fingerprint(of: publicKeyRequest.publicKey)
                if try store.get(fingerprint: fingerprint) != nil {
                    responsePromise.succeed(.success)
                } else {
                    // No matching trusted peer — reject. The peer is
                    // either unpaired or has been revoked since pairing.
                    responsePromise.succeed(.failure)
                }
            } catch {
                responsePromise.fail(error)
            }
        // REMOTE-8.2: reject every non-publickey method immediately.
        case .password, .hostBased, .none:
            responsePromise.succeed(.failure)
        @unknown default:
            responsePromise.succeed(.failure)
        }
    }

    /// Derives a `RemoteIdentityFingerprint` from an `NIOSSHPublicKey`
    /// by parsing the SSH wire format and hashing the raw Ed25519
    /// public key bytes with SHA-256 (the canonical fingerprint per
    /// `RemoteIdentityFingerprint.init(of:)`).
    static func fingerprint(of key: NIOSSHPublicKey) throws -> RemoteIdentityFingerprint {
        var buffer = ByteBufferAllocator().buffer(capacity: 64)
        key.write(to: &buffer)

        // Parse SSH wire format: <u32 type-len><type><u32 key-len><key>.
        guard
            let typeLen: UInt32 = buffer.readInteger(),
            let typeBytes = buffer.readBytes(length: Int(typeLen)),
            let typeName = String(bytes: typeBytes, encoding: .utf8),
            typeName == "ssh-ed25519",
            let keyLen: UInt32 = buffer.readInteger(),
            keyLen == 32,
            let keyBytes = buffer.readBytes(length: 32)
        else {
            throw SSHUserAuthError.unsupportedKeyFormat
        }

        let pubkey = try RemoteIdentityPublicKey(rawRepresentation: Data(keyBytes))
        return RemoteIdentityFingerprint(of: pubkey)
    }
}

public enum SSHUserAuthError: Error, Equatable {
    case unsupportedKeyFormat
}
```

/// @spec REMOTE-8.4
/// Client-side `NIOSSHClientServerAuthenticationDelegate` that verifies
/// the server's offered host key against the pinned record in
/// `PinnedHostStore` for the host the client is attaching to.
public struct PinnedHostKeyAuthDelegate: NIOSSHClientServerAuthenticationDelegate {
    private let expectedFingerprint: RemoteIdentityFingerprint

    public init(expectedFingerprint: RemoteIdentityFingerprint) {
        self.expectedFingerprint = expectedFingerprint
    }

    public func validateHostKey(
        hostKey: NIOSSHPublicKey,
        validationCompletePromise: EventLoopPromise<Void>
    ) {
        do {
            let offered = try SSHUserAuthDelegateBridge.fingerprint(of: hostKey)
            if offered == expectedFingerprint {
                validationCompletePromise.succeed(())
            } else {
                validationCompletePromise.fail(PinnedHostKeyError.hostKeyMismatch(
                    expected: expectedFingerprint,
                    offered: offered
                ))
            }
        } catch {
            validationCompletePromise.fail(error)
        }
    }
}

public enum PinnedHostKeyError: Error, Equatable {
    case hostKeyMismatch(expected: RemoteIdentityFingerprint, offered: RemoteIdentityFingerprint)
}

/// Bridges the wire-format fingerprint extraction logic from the
/// host-side `SSHUserAuthDelegate` so we don't duplicate the SSH
/// wire-format parsing on the client side. We can't import
/// `GrafttyHostAgent` from `GrafttyMobileKit`, so we re-implement the
/// extraction here, keeping it identical to the host-side version.
internal enum SSHUserAuthDelegateBridge {
    static func fingerprint(of key: NIOSSHPublicKey) throws -> RemoteIdentityFingerprint {
        var buffer = ByteBufferAllocator().buffer(capacity: 64)
        key.write(to: &buffer)

        guard
            let typeLen: UInt32 = buffer.readInteger(),
            let typeBytes = buffer.readBytes(length: Int(typeLen)),
            let typeName = String(bytes: typeBytes, encoding: .utf8),
            typeName == "ssh-ed25519",
            let keyLen: UInt32 = buffer.readInteger(),
            keyLen == 32,
            let keyBytes = buffer.readBytes(length: 32)
        else {
            throw PinnedHostKeyError.hostKeyMismatch(
                expected: RemoteIdentityFingerprint(rawBytes: Data(count: 32)) ?? .init(rawBytes: Data(count: 32))!,
                offered: RemoteIdentityFingerprint(rawBytes: Data(count: 32)) ?? .init(rawBytes: Data(count: 32))!
            )
            // ↑ Not a great error — replace with a dedicated "unsupported key format" case
            //   in PinnedHostKeyError if extraction itself fails. See note below.
        }

        let pubkey = try RemoteIdentityPublicKey(rawRepresentation: Data(keyBytes))
        return RemoteIdentityFingerprint(of: pubkey)
    }
}

import CryptoKit

/// Factory for the client-side `NIOSSHHandler`. Encapsulates:
///   - the client identity key (from `ClientIdentityStore`)
///   - the host-key verification delegate (pinned via `PinnedHostStore`)
///   - the transport-protection allowlist (AES-256-GCM only)
///
/// Usage:
///
/// ```swift
/// let handler = SSHClientSetup.makeHandler(
///     clientKey: clientKeypair,
///     expectedHostFingerprint: pinnedFingerprint,
///     allocator: transport.channel.allocator
/// )
/// try transport.channel.pipeline.syncOperations.addHandler(handler)
/// ```
public enum SSHClientSetup {
    public static func makeHandler(
        clientKey: Curve25519.Signing.PrivateKey,
        expectedHostFingerprint: RemoteIdentityFingerprint,
        allocator: ByteBufferAllocator
    ) -> NIOSSHHandler {
        var config = SSHClientConfiguration(
            userAuthDelegate: SingleKeyUserAuthDelegate(key: clientKey),
            serverAuthDelegate: PinnedHostKeyAuthDelegate(expectedFingerprint: expectedHostFingerprint)
        )
        // Mirror the server's cipher restriction on the client side
        // so a man-in-the-middle can't downgrade to a weaker cipher
        // by claiming the server only supports it.
        config.transportProtectionSchemes = [
            AES256GCMOpenSSHTransportProtection.self
        ]
        return NIOSSHHandler(
            role: .client(config),
            allocator: allocator,
            inboundChildChannelInitializer: nil
        )
    }
}

/// Offers a single Ed25519 pubkey on the first attempt; doesn't retry
/// with a different key. Production graftty has one client identity
/// at a time, so single-attempt is sufficient.
private struct SingleKeyUserAuthDelegate: NIOSSHClientUserAuthenticationDelegate {
    private let key: Curve25519.Signing.PrivateKey
    private final class State: @unchecked Sendable {
        var offered = false
    }
    private let state = State()

    init(key: Curve25519.Signing.PrivateKey) {
        self.key = key
    }

    func nextAuthenticationType(
        availableMethods: NIOSSHAvailableUserAuthenticationMethods,
        nextChallengePromise: EventLoopPromise<NIOSSHUserAuthenticationOffer?>
    ) {
        guard !state.offered, availableMethods.contains(.publicKey) else {
            nextChallengePromise.succeed(nil)
            return
        }
        state.offered = true
        let offer = NIOSSHUserAuthenticationOffer(
            username: "graftty",
            serviceName: "ssh-connection",
            offer: .privateKey(.init(privateKey: NIOSSHPrivateKey(ed25519Key: key)))
        )
        nextChallengePromise.succeed(offer)
    }
}
#endif
