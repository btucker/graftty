What counts as involvement?

I would preserve every explicit user message, correction, approval, or decision. Replies that change direction get a short heading explaining the change.

An agent asking a question is still an agent event. Show “You” only when the human actually replies. Color supports the actor label.

A proposed starting rule, rather than a fixed product requirement. The cutoff should follow how much the rows actually occupy.
