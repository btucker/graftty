Sidebar: agent logo stack

The per-agent rows under a worktree are replaced by a small stack of provider logos, one per agent, in gallery order. The first two sketches leave out the worktree icon; the third shows the real row shape. C, X and A stand in for the Claude, Codex and Antigravity marks.

How the stack behaves

  • One logo per agent, in the same order as the gallery tiles, drawn in a single muted tone rather than brand colours.
  • Status is a halo around the logo, in the same colours as the tile dots: an orange halo while that agent asks you something, a pulsing blue halo while it works, none otherwise. Finished agents are dimmed. A logo with a halo is drawn above its neighbours, with the asking one on top.
  • Hovering the stack expands it, so the logos no longer overlap.
  • Resting the pointer on a logo shows the title of that agent's terminal.
  • Clicking a logo selects that agent: the worktree opens with it on stage.
  • More than five agents: the stack shows five and a count.
