Multi-agent worktree: four directions

Rough sketches to react to, not designs. Every one uses the same moment: you are talking to Claude, which started a design review, a code review and a test run in this worktree. The test run has reported back and the code review has a question for you.

All four drop the tab strip, keep every agent one click from a full terminal, and treat the agent you last typed to as the lead.

A. Swim-lane rail — the scroll rail grows a lane per agent

Time runs down the rail, lined up with the lead's scrollback. A helper's lane starts where the lead started it and ends where it reported back. Hover a lane for a gist; click it to open that agent beside the lead.

Good at

Answering "what happened, and when" without leaving the lead. Finished helpers stay visible as history instead of dead tabs.

Weak at

Saying what a helper is doing right now. A lane shows that it is alive, not what it is reading.

Needs

Mostly what exists: start time, messages to the lead, results. The rail gets wider with each live helper.

B. Board strip — kanban of assignments, folded into one line

The cards are pieces of work, not agents. Normally the board is a single line of counts above the terminal; it unfolds when you want the picture. Click a card to open the agent doing it.

Good at

"What needs me?" at a glance. Scales to many helpers, and to work that outlives the agent that did it.

Weak at

Most worktrees have two or three helpers, so three of four columns are often empty. It can feel like a project tool bolted onto a terminal.

Needs

A short title per assignment and a live one-line status per helper. Neither exists today.

C. Stage and gallery — borrowed from video calls

The agent you are talking to has the stage. Everyone else is a small live thumbnail of their terminal at the side. Click a thumbnail to swap it onto the stage; drag it on to share the stage side by side. Type to someone else and they become the lead.

Good at

Seeing motion. You notice a helper is busy or stuck from the shape of its screen, and layout stays as free as today's splits.

Weak at

A terminal shrunk to a thumbnail is texture, not text. The caption has to carry the meaning, and there is no history.

Needs

Small live renders of each terminal, and the same one-line status as B for the captions.

D. Chatter line — helpers get one line, nothing more

If the lead is the interface, helpers may only deserve a single quiet line under its terminal that says what each is up to. It opens into a small roster when you want to drop in.
