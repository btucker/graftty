Details to decide

Status

  • Uses the existing subtle cues: an amber dot for waiting on you, a spinner for working, dimmed text for finished.
  • No colored card backgrounds for status.

Reply inline

  • Option A's inline reply sends text without opening the terminal. It needs a safe path that respects terminal ownership. It could ship later, starting with Open.

Finished agents

  • Finished agents show their result summary on the card instead of a snapshot, and sink below active ones.

Shells

  • Shells list their title and last line. Tapping opens the existing terminal sheet. New terminal lives in the bottom bar.
