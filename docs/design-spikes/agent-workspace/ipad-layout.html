The terminal gets the room. Worktrees collapse to the emoji rail, and agents become a slim vertical strip of provider icons with status badges, with shells below a divider. The identity bar stays compact. It's the best for long sessions, but agent names live only in tooltips and the bar.

Recommendation: A, borrowing B's cards when the sidebar is hidden. A matches the Mac, so the two apps teach each other, and it fixes every problem in today's screenshot without a new navigation model. B is compelling, but a three-column layout fights the terminal for width on an 11-inch iPad. Showing B's cards as the empty state, or when you tap the worktree title, keeps its strength.
