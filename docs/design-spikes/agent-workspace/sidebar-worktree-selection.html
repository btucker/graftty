One worktree, one selection

Uppercase worktree headings, agents indented 18 points, and one continuous selection highlight. PR and Git counts stay on the heading line.

The whole worktree is the navigation target. Clicking its heading, an agent line, or the space within the group opens that worktree. Returning preserves its tabs, split layout, and previous focus. Clicking an agent line does not change the selected agent tab.

The indented lines show which agents belong to the worktree and their shared status glyphs. Agent selection happens in the workspace tabs and panes. The sidebar has no separate agent highlight or agent-level keyboard selection.

The 18-point indent is slightly deeper than the previous 12-point study. Uppercase headings and indentation establish the hierarchy; the background identifies the selected worktree as one unit.

Updated design study. Task labels and states are illustrative; production UI has not changed. PR/MR links and explicit action controls keep their own actions. This supersedes the agent-selection behavior proposed in earlier studies.
