Cleanup and the tab have separate lifetimes. Parent acknowledgment still tears down the completed terminal. The retained tab represents the conversation and does not keep a process alive. Before cleanup, Resume can reuse a healthy live provider instead of creating a duplicate.

Resume is explicit. Selecting a gray tab only shows the result. Resume starts a new assignment generation in the same conversation, so old completion events cannot close the new work. If cleanup is in progress, wait for it to finish before relaunching.

Dismiss the tab when it is no longer useful. Closing a finished tab removes that local view; it does not delete the result or provider conversation. Context can reopen it. A “Close finished tabs” action would keep accumulated records manageable without hiding results automatically.

Example resume failure: “The saved Claude conversation could not be found on this host.” Keep the gray tab, transcript, and Retry action. Starting a new conversation is a separate, explicit choice.

Design study with illustrative results. Resume after terminal cleanup requires new lifecycle and provider-launch support. This supersedes the takeover archive view. The same behavior applies on Mac and mobile; the owning host launches the process.
