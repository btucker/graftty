Emoji header wash

Each worktree already has an emoji identity in the sidebar. This study uses it behind the window header in two layers. A heavily blurred, stretched copy smears color in from the left. A large, lightly blurred, tilted copy sits on the right as a watermark you can still recognize. The goal is ambient recognition: you know which worktree you are in from the top of the window before reading anything.

Click a worktree in the sidebar to switch identity. The controls adjust the live mock when the page runs scripts. The galleries below are static.

What to watch

Legibility

  • A theme-colored scrim sits between the wash and the header text and tabs.
  • The watermark sits behind the header tools. Its opacity has to stay low enough that the glass buttons keep their edges.

Identity and attention

  • The color is ambient and constant, never a status signal.
  • Amber or red emoji compete with the amber needs-input dot on tabs.
  • Worktrees without an emoji show today's header.

Switching

  • Cross-fade the wash over about 200 ms when switching worktrees.
  • The glass tool capsule picks up the color through its backdrop blur.

How it would be built

Two copies of one emoji glyph behind the breadcrumb bar and the tab strip, drawn once. Nothing animates and nothing touches the terminal surface.

struct WorktreeEmojiWash: View {
    let emoji: String
    let theme: GhosttyTheme
    var body: some View {
        ZStack {
            Text(emoji)                                    // left color smear
                .font(.system(size: 420))
                .scaleEffect(x: 2.4, y: 1, anchor: .leading)
                .saturation(1.7)
                .blur(radius: 44, opaque: false)
                .opacity(theme.isDark ? 0.55 : 0.42)
                .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .leading)
                .mask(LinearGradient(stops: [.init(color: .black, location: 0.4),
                                             .init(color: .clear, location: 0.7)],
                                     startPoint: .leading, endPoint: .trailing))
            Text(emoji)                                    // right watermark
                .font(.system(size: 176))
                .blur(radius: 2.5)
                .rotationEffect(.degrees(-12))
                .opacity(theme.isDark ? 0.2 : 0.17)
                .frame(maxWidth: .infinity, alignment: .trailing)
                .offset(x: 34)
        }
        .overlay(theme.background.opacity(0.26))           // legibility scrim
        .clipped()
        .drawingGroup()
        .allowsHitTesting(false)
    }
}
