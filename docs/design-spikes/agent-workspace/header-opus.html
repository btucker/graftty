Header hierarchy study

The trailing half of the header holds three unrelated things that look like one cluster. Context toggles the worktree inspector. The bordered chip is the pull request, not a preview, which is why it read as one. The document icon with a chevron is the file preview menu. They share no grouping, no common control style, and no label tells them apart.

Each option below keeps Back, Forward and the worktree breadcrumb. It keeps New agent as the trailing tab action and leaves the accepted sidebar decisions alone. Every window shows a preview open, so you can see which control owns it.

Recommendation: option A, Identity and tools. It fixes the mess by sorting controls by what they belong to, without changing how previews or the inspector work. The PR becomes part of the worktree's name. The right edge keeps only window tools, styled alike, with the inspector toggle last as macOS apps place it. Option C is the clearest model but changes what a tab means. Option B is the calmest header but hides PR status behind a click.

Narrow width, sidebar hidden. The repo name drops first. The worktree name truncates in the middle only after that. The preview button shrinks to its icon, so the tray header takes the file name back.

Gains

  • The two sides each answer one question, where you are and what is open.
  • The PR keeps its at-a-glance state when the sidebar is hidden, at a fraction of the width.
  • No model change: the preview stays a pane overlay, and Context stays the inspector.

Costs

  • The word Context becomes an icon with a tooltip. It's native, but less obvious to a newcomer.
  • The PR title is one hover or one inspector away.
  • The ring color carries the check state, so the tooltip and accessibility label must also say it.

B. One inspector

The header holds navigation, identity and a single inspector toggle. The inspector gains a segmented control: Summary, Pull Request, Previews. Choosing a preview from the list opens it in the pane. Status lives on the sidebar name line, which already shows the PR number.

C. Previews are tabs

The header belongs to the worktree: navigation, identity, a compact PR chip, and Context. The tab row belongs to content. An open preview becomes a document tab beside the agents, with its own close button, and New agent stays trailing. The preview no longer floats over an agent.
