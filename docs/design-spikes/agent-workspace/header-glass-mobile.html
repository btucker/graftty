Terminal1 shell

The agent keeps its place in the switcher, with a dimmed title and completion mark. Opening it shows its result and saved transcript. Resume starts that exact conversation again.

A child finishing never opens this screen automatically. The parent’s cleanup releases the process, while the conversation stays available. The user can keep reading another agent or working in the Terminal sheet.

Selecting an agent or opening Terminal on a phone does not change the Mac’s selected tab, split layout or focus.

States to test before shipping the mobile design
  • First shell creation, reopened shell, and multiple shells.
  • Keyboard, rotation, split-screen iPad and compact landscape.
  • Hidden agent needs input or finishes while the shell is open.
  • Finished conversation resumes after reconnecting to the host.
  • Large text, VoiceOver, increased contrast and reduced transparency.

Material guidance: Apple · Adopting Liquid Glass. Web material and symbols are approximations. Task text is illustrative. This page proposes the glass treatment and mobile adaptation; it does not replace the running app.
