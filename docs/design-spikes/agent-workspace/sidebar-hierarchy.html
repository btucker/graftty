Same data, same row heights, same status glyphs. Compare letter case first, then the added agent indent. PR and Git counts stay beside the worktree name.

My preference is caps with the small indent. Worktrees read as headings; agent tasks read as the destinations inside them. Keep the headings muted and compact, with normal-case task names. Selection stays on the agent row.

The cost is earlier truncation. Caps use more horizontal space, and the indent takes another 12 points from tasks. Keep the indent shallow and preserve the full worktree name on hover.
